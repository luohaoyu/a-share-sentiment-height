# 交易决策框架 → 情绪层口径映射

本文件是 `ai_analysis`（报告「AI 分析」页）的**口径说明书**，解决一个具体问题：
框架原文只在代码的 `if/elif` 里活着，换会话、换人、框架升级时没人知道该对齐哪里。

- **本文件是什么**：把《交易决策框架总结》中**本技能数据能判定**的部分，逐字段写成可核对的取数口径。
- **本文件不是什么**：不是框架全文，不是交易建议，不能作为个股买卖依据。

| 项 | 值 |
|---|---|
| 来源文档 | 《交易决策框架总结 V2.1.1.1》（飞书 doc，nodeId `pYTiEKbZc68GyhWMDd3LIA`） |
| 采用层级 | **仅情绪层**（周期分类 + 环境约束） |
| 规则实现 | `assets/ai_rules.json`（唯一口径来源）+ `scripts/report/to_contract_data.py::build_ai_analysis` |
| 引擎标识 | `rule-synthesis-v1`，写入 `ai_analysis.engine` |
| 合规 | 输出必带 `disclaimer`：规则引擎合成、不含均线/板块/个股判断、**不构成投资建议** |

> 改阈值或文案 → **只改 `assets/ai_rules.json`**，不要改 Python。代码里不再硬编码任何阈值。

## 一、能做 / 不能做（先看这条，比规则本身更重要）

框架共四层：情绪层 → 模式层 → 策略层 → 执行层。本技能是**数据统计技能**，只覆盖情绪层的**高度与广度**两条证据，因此：

| 框架要素 | 本技能 | 处理方式 |
|---|---|---|
| 市场涨幅空间（高度趋势） | ✅ 有 | 直接判定 |
| 创新高能力（最新 vs 区间峰值） | ✅ 有 | 直接判定 |
| 达标广度（当日达标股只数） | ✅ 有（**实现层扩展**，原文状态卡无此项） | 作为「领涨股群响应广度」的量化代理 |
| 领涨股群（当日榜首/连板/换人） | ✅ 有 | 直接填充 |
| 5 日、10 日均线承载 | ❌ 无 | **标「未覆盖」，禁止推断** |
| 板块承接 / 扩散 | ❌ 无 | **标「未覆盖」，禁止推断** |
| 个股操作级别、买卖点 | ❌ 无 | **标「未覆盖」，禁止推断** |
| 单笔风险 1–2%、单票 ≤ 总仓 1/6、连板接力 ≤ 总仓 1/2 | ❌ 无持仓数据 | 只作边界说明，**不由本技能计算** |

**硬约束**：`ai_analysis.fields` 中凡属上表 ❌ 的，值必须以「未覆盖：…」开头（清单在 `ai_rules.json.uncovered_fields`）。任何情况下不得用情绪高度去反推均线或板块结论。

## 二、情绪层状态卡 → 本技能取数口径

框架原文的每日状态卡有 7 项；本技能输出 7 项判定 + 3 项「未覆盖」说明，共 10 行。

| 状态卡字段 | 原文取值 | 本技能取数 | 判定阈值（`ai_rules.json`） |
|---|---|---|---|
| 周期内领涨股群 | 原核心 / 新核心 / 掉队个股 | `height.points[-1]` 的 `leader_name`、`leader_code`、`leader_streak`、`leader_changed` | 无阈值，直接呈现 |
| 创新高能力 | 继续创新高 / 修复但不创新高 / 修复失败 | `latest.value` vs `peak.value` | `new_high_ratio=0.999`；距峰回撤 `deep_drawdown=-0.20` |
| 市场涨幅空间 | 继续抬高 / 停止扩张 / 持续收缩 | 同上 | 与创新高同源：创峰→抬高；回撤 ≤ −20% → 收缩；否则停止扩张 |
| 广度响应 | （原文无此卡项） | `points[].count` 最新值 vs `breadth_lookback=5` 个交易日前 | 增→扩张 / 减→收缩 / 等→持平 |
| 分歧演化 | 中继 / 延续 / 转折 | 创新高能力 × 市场涨幅空间 的组合 | 见下表 |
| 情绪周期 | 上涨 / 盘整 / 下跌 | 由分歧演化一对一映射 | 中继→上涨 / 延续→盘整 / 转折→下跌 |
| 观察阶段 | 分歧前预判 / D0 / D1—D3 | 距最近一次断档的交易日数 | `break_change=-0.20` 记一次断档；`stage_window=3` 内显示 `D{n}`，否则「常态跟踪」 |
| 5/10 日均线承载 | 延续 / 争夺 / 失守后无法恢复 | — | 未覆盖 |
| 板块承接 | — | — | 未覆盖 |
| 个股操作级别 | — | — | 未覆盖 |

**断档定义**：`height.points[].change ≤ break_change`（默认 −20pp），即单日情绪高度骤降，对应原文「原核心修复失败 / 负反馈扩散」的市场级信号。

## 三、周期三态判定表（原文表 + 本技能实现）

| 情绪周期 | 对应分歧状态 | 原文策略层约束 | 本技能 stance |
|---|---|---|---|
| **上涨** | 分歧中继 | 仅在承接、创新高和空间扩张条件成立后，进入顺势进攻评估 | `顺势进攻` |
| **盘整** | 分歧延续 | 以观察和分歧承接确认优先，空间未重新抬高前控制风险暴露 | `分歧承接（观察为主）` |
| **下跌** | 分歧转折后的结果 | 停止新增风险，进入防守约束，等待新结构证据 | `防守退出` |

过渡态：原文明确「分歧转折观察期」**不是第四种周期**，只是过渡。本技能的处理是——
转折已判定时，若距最近断档 ≤ `recovery_window`（默认 3 个交易日），判 `切换试错（小规模分批）`，
否则判 `防守退出`。这样「刚转折、还有观察窗」与「转折已成」不会混为一谈。

**分歧演化判定矩阵**（实现于 `build_ai_analysis`）：

| 创新高能力 \ 市场涨幅空间 | 继续抬高 | 停止扩张 | 持续收缩 |
|---|---|---|---|
| 继续创新高 | 中继 → 上涨 | 延续 → 盘整 | 延续 → 盘整 |
| 修复但不创新高 | 延续 → 盘整 | 延续 → 盘整 | 延续 → 盘整 |
| 修复失败 | 延续 → 盘整 | 延续 → 盘整 | **转折 → 下跌** |

即只有「同时创新高且空间抬高」才是中继，只有「修复失败且空间持续收缩」才是转折；
原文对此有明确要求——单只个股跌破 5 日线、单日冲高回落、局部反抽，都不足以确认转折。

## 四、四类行动策略（原文）与本技能对应

| 策略 | 原文适用状态 | 本技能输出 |
|---|---|---|
| **顺势进攻** | 上涨周期中的分歧中继，且领涨股群继续创新高、市场空间抬高 | 分歧演化=中继 |
| **分歧承接** | 盘整周期中的分歧延续，或上涨周期中的分歧预警/确认未完成 | 分歧演化=延续 |
| **切换试错** | 分歧转折连接两个周期，新领涨股群尚未确认 | 转折且处于断档后观察窗内 |
| **防守退出** | 分歧转折确认、下跌周期形成、空间持续收缩或退潮加速 | 转折且已过观察窗 |

总仓位方向随 stance 输出（`advice.position`）：进攻→可提高；承接→控制、轻仓试错；试错→小规模分批、不提高；防守→降仓或空仓。
**注意**：这是**方向性约束**，不是仓位数值；数值上限属框架执行层，本技能不计算。

## 五、输出结构与可审计性

`ai_analysis` 字段（契约 `assets/report.contract.json` → `ai_analysis`）：

| 字段 | 含义 |
|---|---|
| `engine` / `framework` / `as_of` | 引擎标识、框架版本、判定基准日 |
| `summary` | 一段话结论（`ai_rules.json.summary.template` 渲染） |
| `fields[]` | 状态卡，10 行（7 判定 + 3 未覆盖） |
| `conditions.成立 / 待确认 / 失效` | 三条件，对应原文状态卡的「已成立 / 待确认 / 失效条件」 |
| `advice.period / divergence / stance / position` | 周期、分歧、策略约束、总仓位方向 |
| `disclaimer` | 免责声明（必填） |

审计要求：`fields` 的每个值都必须能回溯到 `height` 里的具体数字或 `ai_rules.json` 的某个标签，
不允许出现「本报告未提供的数据」被描述成结论。
